Feed string to any awake heart. The default recipe spends **two breaths and four seconds** to weave one Hollow Thread. An amethyst shard supplies 32 breaths. Full output pauses the work and preserves the input.

For hoppers and Fieldframe item ports, the top and side faces accept string and amethyst. The bottom exposes completed thread. Unsided machine access is closed. The Keeper's nest is private.

A comparator reads stored breaths at one signal strength per 16 breaths, up to 15. A Listener's redstone output is its taught phrase. Use the marked front face for teaching its input.

A Keeper gives a one-second, strength-15 greeting through the unmarked faces when it gathers its favourite item. An ordinary offering does not start a greeting. Consecutive favourites extend the current greeting. Connect this output to a lamp or a Listener's marked teaching face to build an arrival signal. The comparator continues to read breaths.
