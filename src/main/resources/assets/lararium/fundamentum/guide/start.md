## First steps

- Craft a **Hollow Heart** and a **Tuning Fork**.
- Build a small closed room with walls, a floor and a roof of any ordinary block.
- Set the heart on the floor with air above it, within eight blocks of the walls.
- Ring the fork against the heart. Stitches trace the room. Amber stitches show a leak.
- Close each leak. Doors count as closed. A **Threshold Veil** makes an open doorway that still counts as closed.
- Feed the inhabitant an amethyst shard. Each shard gives **32 breaths**.

## Living with it

- Feed it string to start weaving. Use it with an empty hand to take finished thread.
- Sneak with an empty hand to take back unused input.
- A name tag names it.

## If the room opens

The inhabitant falls asleep and keeps its name, items and phrase until the room is closed again. Breaking the heart drops its items and stores the rest in the heart, so it wakes in any new closed room. Each heart needs its own room.

Four lives can grow from a room. They are [the Keeper](lararium:keeper), [the Breather](lararium:breather), [the Listener](lararium:listener) and [the Shelter](lararium:shelter).
